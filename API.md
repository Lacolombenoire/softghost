


Voici les requêtes API que vous pouvez effectuer sur le serveur :


+ http://localhost:3000/api/admin/statistiques
obtenir les informations nécessaires lorsqu'on n'est un administrateur. Obtenir de l'information Quant au nombre de places disponibles et savoir si une session de formation et pleinne.


+ http://localhost:3000/api/formations-disponibles
ne retourne que les formations disponible ainsi que leur nombre de participants


+ http://localhost:3000/api/formations
lister les formations disponible
